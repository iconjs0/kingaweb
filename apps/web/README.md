# Web Application

KingaWeb's responsive customer interface, built with Next.js, TypeScript and React.

## Development

From the repository root:

```bash
pnpm install
pnpm dev
```

Open `http://localhost:3000`.

The interface owns onboarding, verified assets, findings, remediation workflows, reports, settings, accessibility and English/Kiswahili presentation. It must not perform scanning directly or make authorization decisions that are trusted without server-side enforcement.
